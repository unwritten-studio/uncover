# Uncover – Hinweise für Claude

## Einstieg

Zuerst lesen: `README.md`, `ROADMAP.md` (Stand und nächster Schritt), dann `docs/`.

## Arbeitsweise

- Direkt auf `main` committen und pushen, keine Pull Requests – solange nur eine Person am Repo arbeitet (Entscheidung vom 30.10.2026). Kommt jemand dazu, wird das neu festgelegt.
- Kleine, abgeschlossene Commits. Tests vor jedem Commit: `python3 -m unittest discover werkzeuge`
- `ROADMAP.md` nach jedem Schritt aktualisieren – sie ist der Übergabepunkt zwischen Sitzungen und Rechnern.
- Vor Beginn `git pull`, nach Abschluss `git push`.

## Sprache

Dokumentation, README, Roadmap, Berichte: nur Deutsch. unwritten tritt auf Deutsch auf, und Bernd muss alles lesen können. Code und Commit-Nachrichten: Englisch.

## Öffentliches Repository

Das Repository ist öffentlich. Über das lokale Modell steht hier nur „lokales Modell“ – kein Modellname, keine Hardware, kein Host, keine Speicherangaben. Das gilt für Dateien, Commits, Issues und alles andere, was auf GitHub landet. Diese Details stehen ausschließlich im internen Kontext.

Bernds PDFs kommen nie ins Repository, auch nicht als Release-Anhang.
